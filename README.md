# Customer Shopping Behavior Analysis

## 📊 End-to-End Data Analytics Project

This project analyzes customer shopping behavior using an end-to-end data analytics workflow, from data preparation and exploratory analysis to SQL business analysis and interactive Power BI dashboard development.

The goal is to transform raw customer shopping data into meaningful business insights that can support better decisions around customers, products, revenue, subscriptions, discounts, shipping, and purchasing behavior.

---

## 🎯 Project Objectives

The project aims to answer key business questions such as:

1. What is the total revenue generated by male vs. female customers?
2. Which customers used discounts but still spent more than the average purchase amount?
3. Which products have the highest average review ratings?
4. How does average spending differ between Standard and Express shipping?
5. Do subscribed customers spend more than non-subscribed customers?
6. Which products have the highest percentage of purchases with discounts?
7. How can customers be segmented into New, Returning, and Loyal customers?
8. What are the top 3 most purchased products within each category?
9. Are repeat buyers more likely to subscribe?
10. What is the revenue contribution of different age groups?
